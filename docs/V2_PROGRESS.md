# V2.0 升級進度

## 四階段目標

1. 資料穩定：歷史行情回補、統一交易日、缺漏偵測與異常警示。
2. 回測可信：公司事件、實際交易成本、樣本外測試。
3. 選股優化：同條件比較淨報酬、回撤與不同市場環境。
4. 盤後決策：每日候選股、觀察價位、風險及失效條件。

## 第一階段：進行中

- 已有固定 2026 年 3～6 月 TWSE 回補，每批最多 5 檔，逐月補缺，不覆寫既有行情。
- 排程只有在 `TWSE_MAR_JUN_AUTO_ENABLED=true` 時才會寫入；新增檢查不改變此開關。
- 官方首次上市日核對：包括 7867（2026-10-30），不再將其上市前月份當作下載失敗。未知上市日期不推測成無資料。

- 新回補摘要分列已回補、上市前、待回補、冷卻中、人工核對；本批成功不代表整體完成。
- `python twse_mar_jun_auto.py --status-only` 只查資料庫與目前上市清單，不下載月行情、不寫入資料庫。
- `V2 Data Stability Checks` 在 PR 執行離線測試；合併至 main 後額外執行唯讀覆蓋檢查並顯示排程開關。
