# V2.0 升級進度

## 四階段目標

1. 資料穩定：歷史行情回補、統一交易日、缺漏偵測與異常警示。
2. 回測可信：公司事件、實際交易成本、樣本外測試。
3. 選股優化：同條件比較淨報酬、回撤與不同市場環境。
4. 盤後決策：每日候選股、觀察價位、風險及失效條件。

- 新增 `daily_gap_audit.py`：以 `TWSE`／`TPEX` 有足夠行情的**共同日期**作為比較基準，不將週末或未知休市日期直接認定為缺漏。

## 2026-11-20：趨勢交易研究計畫 v0.1

原先進場節奏畫面只呈現「型態／風險」；依使用者「找合理進場位置、跟上上漲趨勢、知道何時檢討退出」的目標，加入第二層研究計畫 \`trend_following.py\`，**並非真實買賣建議或已驗證的獲利策略**：
